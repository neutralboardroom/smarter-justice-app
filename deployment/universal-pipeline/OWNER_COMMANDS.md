# Owner Deployment Commands

Roger Gillman gives ordinary deployment instructions only in the Smarter Justice master builder chat.

Examples:

- `Deploy the latest qualified Divorce Law Aid release.`
- `Deploy Smarter Justice v1.7.85 after every required gate passes.`
- `Deploy all currently qualified releases; skip anything that fails an owner rule.`

The master chat must resolve the exact product repository, version, commit, release evidence, migration class, backup receipt, Render service, health contract, and rollback target before invoking a production workflow.

A command in a worker chat may build or qualify that worker's product, but the central portfolio deployment record remains controlled from the Smarter Justice master chat.
