# Cross-Portal Learning Packet — v1.7.51

## Candidate shared standards
1. **Safety-critical portal acceptance overlay** — ADAPT for any portal handling unusually sensitive location, contact, narrative, upload, or notification data.
2. **Historical alias non-reassignment** — ADOPT where legacy labels mix people, organizations, services, and specialties.
3. **No-save public starting page** — ADAPT for safety-critical preliminary routing before secure infrastructure exists.
4. **Separate identity, authority, specialty, service, publication, and payment states** — ADOPT portfolio-wide.
5. **Dependency-independent default test suite with external-infrastructure tests separated** — ADOPT portfolio-wide.

Never share survivor narratives, safety plans, precise/confidential locations, uploads, identity evidence, credentials, sessions, MFA secrets, payment data, private support notes, or production personal data.
