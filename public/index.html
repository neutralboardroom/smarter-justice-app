A Justice Truck public-service initiative

The Stop Sign Project

The Stop Sign Project places durable domestic-violence resource signs where someone may be able to see help information privately. It is an active Justice Truck and Smarter Justice public-service initiative.

Need help now? In immediate danger, call 911. For confidential support, call 800-799-SAFE (7233) or text START to 88788. Internet activity may be monitored, so consider using a safer device when necessary.
