# Smarter Justice Preservation Vault

This directory is the canonical small index/provenance layer for the Universal Smarter Justice preservation vault.

## Normal Roger workflow

Roger should normally need only:

1. the latest **lean Universal Smarter Justice ACTIVE ZIP**;
2. the latest **Universal Smarter Justice Builder ZIP**;
3. the instruction **START NOW**.

Do not require Roger to re-upload previously accepted donor portal ZIPs unless the indexed preserved source is unavailable or a deliberate byte-for-byte re-audit is required.

## Storage model

- Keep this index and small provenance/receipt files in the `neutralboardroom/smarter-justice-app` GitHub repository.
- Keep large exact donor ZIPs outside normal Git history. The current primary bulk backend is the user's ChatGPT Library under `/Smarter Justice Preservation Vault/`.
- Copy the current vault index into every lean ACTIVE Smarter Justice artifact.
- Do not nest prior portal ZIPs, predecessor ACTIVE ZIPs, or redundant historical archives inside the routine ACTIVE artifact.

## No-loss requirement

Externalizing bulk is not permission to drop functionality. Before an expanded donor tree can be removed from ACTIVE, preserve its exact filename, size and SHA-256 in `INDEX.json`, retain or supersede its functional routes/tools/branding/funnels/profiles/data/tests/schemas/provenance in the current Smarter Justice module/runtime, and retain enough receipts to recover the exact donor when needed.

## Architecture

Universal Smarter Justice remains one central runtime and one release train. Divorce, Family Law, Estate, Immigration and other legal areas are specialty modules. Approved specialty domains are direct entrances into those modules; they are not separately advancing applications by default.

## Recovery

When historical source is needed, read `INDEX.json`, retrieve the indexed donor from the storage backend, verify byte size and SHA-256 before extraction, and treat historical donor startup/build instructions as provenance unless current Universal Smarter Justice authority explicitly adopts them.
