# Smarter Justice v1.7.8 No-Change Ledger

Prepared: July 21, 2026

This release follows the rule that no change should be made merely to create a version. The following areas were audited and intentionally preserved because changing them was not supported by evidence of a user benefit in this release.

## Preserved without functional expansion

- 69-practice-area catalog and 74-row official-source catalog
- Separate portal repositories, brands, versions, deployment truth, and governance boundaries
- Immigration Oasis separation
- Stop Sign Project separation and confidential domestic-violence boundary
- Public professional directory architecture
- Profile claim, correction, removal, duplicate, source, and credential foundations
- Firm profiles, seats, memberships, recurring billing architecture, and professional account security
- Existing pricing amounts and membership structure
- Existing referral, Community Partner, and attribution architecture
- Existing owner and staff access models
- Existing PostgreSQL migration and durability foundations
- Existing CSRF, session, MFA, recovery, revocation, upload validation, rate limiting, and security headers
- Existing official-source and form-governance rules
- Existing Human Review Specialist and licensed-professional role separation
- Existing no-guarantee, non-affiliation, and fee-separation principles
- Existing Justice Truck and Smarter Justice brand relationship
- Existing visual logo and core color identity
- Existing external integrations and provider choices
- Existing production infrastructure records

## Gates intentionally left closed

- Confidential production uploads
- Sensitive saved-case traffic
- External AI processing of sensitive information
- Professional membership payment activation
- Public Human Review payment activation
- Supporter subscriptions
- Public consultation booking
- Public reviews
- Unrestricted professional matching
- Automatic professional routing
- Automatic cross-portal data transfer
- AttorneyRide transfer without separate consent
- Automatic court, agency, insurer, tax, benefit, or government filing
- Unverified Stop Sign Project destination activation
- Broad public launch

## Changes rejected as unnecessary churn

- No framework rewrite
- No database redesign
- No mass route renaming
- No brand redesign
- No pricing experiment
- No practice-area expansion
- No speculative AI provider integration
- No new payment product
- No directory-ranking algorithm change
- No automatic lead-routing change
- No deployment merely because the code passed locally

## Changes accepted because the audit showed a user benefit

- Public-first homepage and clearer professional path
- Quick-start examples and completion expectations
- Clear post-result actions
- Saved-work dashboard language and runtime message boundary
- Focused website availability language
- Form, human-review, payment, kiosk, and practice-page wording
- Professional dashboard and membership wording
- Mobile action stacking, touch targets, wrapping, and anchor visibility
- Stronger customer-language and customer-experience regression tests
