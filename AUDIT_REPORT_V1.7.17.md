# Smarter Justice v1.7.17 Audit Report

Prepared: July 21, 2026

## Verified baseline

The authoritative v1.7.16 ZIP matched its recorded SHA-256, size, inventory, root layout, and archive-safety evidence. The untouched 30-part regression suite passed with temporary external test-only `pg` and `nodemailer` compatibility modules because the package registry was unavailable.

## Evidence-backed finding

Users could review text, compare versions, and build a source-linked action plan, but they lacked an end-to-end private workflow for preparing a factual question or letter from confirmed source lines. The Free Tools action-plan link also targeted a missing anchor.

## Implemented improvement

v1.7.17 adds a device-only communication-preparation workflow with affirmative source selection, user-entered facts and request, editable draft, separate exact-line appendix, local download, and clear controls. It also corrects the action-plan deep link.

## Preserved boundaries

No AI provider, message sending, account save, browser persistence, analytics, professional contact, inquiry, booking, payment, confidential upload, deadline calculation, routing, review, or filing capability was added. Directory totals remain 27 public records and 23 strict qualifying profiles.

## Remaining limitations

Real-device and assistive-technology acceptance, production database/email/payment/support/legal/monitoring evidence, controlled deployment, and all external P0 gates remain open.


## Dependency verification limitation

A registry-backed clean `npm ci --omit=dev --ignore-scripts` returned HTTP 503 from the package registry during controlled retries. The complete 31-part regression suite passed with temporary external test-only `pg` and `nodemailer` compatibility modules that are not included in the release. The 15 locked dependency records are unchanged from v1.7.16 except for the root package version. No fresh vulnerability count is claimed until a registry-backed install and advisory query succeed.
